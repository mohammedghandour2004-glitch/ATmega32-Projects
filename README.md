# ATmega32-Projects

A collection of embedded systems projects developed using the ATmega32 microcontroller, Embedded C, and Proteus.

## Projects

### 01. ATmega32 Digital Door Lock

A password-based digital door lock system using a 4x4 keypad, 16x2 LCD, LEDs, and buzzer.

**Technologies:** Embedded C, ATmega32, Keypad, LCD, Proteus

More projects will be added to this repository over time.
